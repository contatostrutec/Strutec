# STRUTEC Construções Metálicas — Site

Landing page institucional da STRUTEC (estruturas metálicas, mezaninos, galpões, coberturas e Steel Deck) em Brasília e região.

## Estrutura

```
strutec-site/
├── index.html
├── css/style.css
├── js/main.js
├── images/
└── .nojekyll
```

## Publicar no GitHub Pages

1. Crie um repositório no GitHub (ex.: `strutec-site`).
2. Envie o conteúdo desta pasta para a raiz do repositório (o `index.html` precisa ficar na raiz).
3. Em Settings → Pages, escolha "Deploy from a branch", branch `main`, pasta `/ (root)`.
4. Em poucos minutos o site fica em `https://SEU-USUARIO.github.io/strutec-site/`.
